This is my advanced game design project.

This aims to create an enemy pathfinding AI that is able to map surrounding environments dynamically to reach the target at the centre of a procedurally generated maze. The user is able to place down a single wall using right click and remove walls using left click.

There are sliders present to change the depth and/or width of the maze.
